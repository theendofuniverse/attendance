# What is Machine Learning?

## Introduction
Machine Learning (ML) is a branch of Artificial Intelligence (AI) that allows computers to learn from data and improve their performance without being explicitly programmed for every task.

In simple words, Machine Learning teaches computers how to learn from experience, just like humans learn from examples.

## How Does Machine Learning Work?
Machine Learning works in a few basic steps:

1. **Collect Data:** Gather information that a computer can learn from.
2. **Prepare Data:** Clean and organize the collected data.
3. **Train the Model:** Feed data to an ML algorithm so it can learn patterns.
4. **Test the Model:** Check how accurately the model makes predictions.
5. **Make Predictions:** Use the trained model to predict results from new data.

## Types of Machine Learning

### 1. Supervised Learning
The computer learns from labeled data (data that already has correct answers).

Examples:
- Email spam detection
- House price prediction
- Student result prediction

### 2. Unsupervised Learning
The computer learns patterns from data without predefined answers.

Examples:
- Customer segmentation
- Grouping similar products
- Finding hidden patterns in data

### 3. Reinforcement Learning
The computer learns by taking actions and receiving rewards or penalties.

Examples:
- Training robots
- Self-driving systems
- AI game-playing agents

## Applications of Machine Learning
- Voice assistants
- Face recognition
- Recommendation systems (Netflix, YouTube)
- Fraud detection
- Medical diagnosis support
- Self-driving cars

## Conclusion
Machine Learning is an important technology that helps computers learn from data, identify patterns, and make intelligent decisions. It is widely used in our daily lives and plays a major role in the future of technology.
